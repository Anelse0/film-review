# 审阅标准：七道关、十七个维度

目录：怎么用 · 规则关 · 意图关 · 调度与表演关 · 镜头语言关 · 光与质感关 · 剪辑关 · 可行性关 · 裁决 · 被关掉的手段 · 与 film-director 的分工 · 失败信号速查

## 怎么用

每个维度写：**怎样算好**、**读卡的哪里**、**怎么查**（审阅时真的去做的动作）、**失败信号**、**哪一步可审**（方案 = 停在方案这一步，只有机位表、走位表、镜头纵览；分镜卡 = 逐镜五层与资产计划都在）、**判定**、**典型严重度**、**依据**（人名与出处的细节在 `sources.md`）。

判定分三档：**方案可审**＝只看文字就能判；**设计可审，效果看成片**＝方案里判"有没有设计、设计对不对"，效果进成片验收清单；**看成片**＝方案阶段只确认有对应的设计。

维度在意见里按名字引用，不编号。没有问题的维度不写。

## 规则关

### 本剧规则先行

- **怎样算好**：方案覆盖本剧全部适用的硬规则和用户点名过的类别；和本剧规则的冲突逐条列出、交用户定；规则之外的新做法登记成例外并写理由；手法分布和正面样例像同一部剧，不像"每周换一部剧"。
- **读哪里**：执行卡"偏好冲突""用户已点名"两行；手法分布；贯穿要求；镜头纵览。
- **怎么查**：拿审阅档案的硬规则逐条对纵览与 C 层；默认值的每处偏离找理由；把手法分布和档案里的正面样例并排看。
- **失败信号**：执行卡写"无冲突"，纵览里却有违反；用户点名过的类别同样的问题又出现；新手法没进风险登记；和正面样例的语法明显不同又没说为什么。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：违反硬规则致命；默认值偏离没写理由、语法漂移重要。
- **依据**：《王冠》《心灵猎人》的成文规则与器材固化；Mimi Leder（没有监制导演的剧每周都像另一部剧）；Viet Nguyen（每部剧有自己的文化）。

## 意图关

### 意图可追溯

- **怎样算好**：有一句话的核心（不是剧情梗概），能拿来否决一个具体的镜头选择；随机抽三镜，景别、运动、光都能指回它；写出本场"不能拍成什么样"和因此排除的手段；场景目标和结束点清楚。
- **读哪里**：卡头视觉方案、观众问题、场景参数卡、峰值事件、风险登记；各镜 A 层。
- **怎么查**：抽三镜做追溯——这个景别、这个运动、这道光，是从意图句的哪几个字来的？拿意图句去否决一个镜头：否决不了任何东西的意图句等于没有意图。删除测试：删掉这一镜，故事缺不缺？
- **失败信号**：视觉方案是剧情复述；意图只是形容词（温馨、紧张、电影感）；每镜的选择只能用"好看""有张力"解释；只有执行层（"50mm、低机位、侧逆光"）没有意图和规则；规则写了，逐镜不遵守。
- **哪一步可审**：方案。**判定**：方案可审。
- **严重度**：意图缺失或裁决不了镜头致命（退回方案层）；局部镜头追溯不到重要。
- **依据**：Lumet 先问"这部片讲的是什么"，《电视台风云》讲腐败，于是让摄影机一路"被腐蚀"；Coppola 导演本每场的 The Core 与 Pitfalls；Fincher 每场必须完成的几件事；Mamet 删除测试。

### 视点与信息差

- **怎样算好**：写明这是谁的戏，观众比人物知道得多、少还是一样，要悬念、惊奇还是好奇；视点落到至少一个可查的参数上（机距与焦距感、谁的反应被采用、谁的视线镜头成立、信息插在哪）；违背视点的镜头单列理由；视点转移标出在哪一镜；悬念写明在本条还是哪一集释放。
- **读哪里**：卡头视点、观众问题、场景参数卡的"信息"项；纵览的焦点列与角度列；E 层反应镜清单。
- **怎么查**：冷读里"这是谁的戏"的答案，和方案写的视点主人一致吗？数一数谁的反应镜最多、最近、最长。逐拍问观众此刻知道什么：有没有提前泄露、信息被反向揭示、同一信息给了观众又在人物脸上再演一遍？看—所见—反应三联成立吗？
- **失败信号**：反应镜在两人之间平均分配，观众不知道跟谁；悬念建立了没有释放；视点无理由跳换；关键信息被插入镜提前交给观众，人物的发现因此失效（除非就是要悬念）。
- **哪一步可审**：方案、分镜卡。**判定**：设计可审，效果看成片。
- **严重度**：视点归属错位、信息反向揭示致命；视点模糊重要。
- **依据**：Hitchcock 的悬念与惊奇；Mackendrick 的隐形见证者；《奥本海默》彩色与黑白按视点分轨；《沙丘 2》在设定的时刻把视点交给 Chani。

## 调度与表演关

### 调度先于机位

- **怎样算好**：走位先成立，机位为捕捉走位而设；距离、朝向、交叉、遮挡与露出承载关系的变化；对话戏不默认"站着念词 + 单人对切"，至少考虑过双人或纵深关系镜；不说话的人写明看哪里、动不动；峰值动作有一段走位撑着。
- **读哪里**：走位表（动线含义列）、机位表、卡头调度模式。
- **怎么查**：只看走位表，关系有没有变（谁靠近、谁退、谁转身、谁被挡住又露出来）？机位表里每个机位是为哪段走位设的？峰值那几秒，走位表里有没有动作？
- **失败信号**：走位表全是"持续不动"；对话戏通篇单人近景正反打，人物像"在说话的照片"；走位和机位互相打架；不说话的人没有状态。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：峰值没有走位撑着、通篇单人对切又没理由，重要。
- **依据**：Spielberg 用调度在一个镜头里完成几个构图；Lumet 排练时连走位一起走；Mylod《继承之战》的"隐身调度"、扔掉教科书式覆盖；Bordwell 的遮挡与显露；Hitchcock 反对"拍人说话的照片"。

### 表演写成可演的动作

- **怎样算好**：表演拍子写成人物在对对方做什么、手上在做什么，不写情绪结果或"让观众觉得"；起态承接上一镜同一人物的末态；关键情绪拍放在最可见的景别和够用的时长里，保险镜头不挤掉它；不把一个情绪拍拆成好几个特写。
- **读哪里**：各镜有序表演块、表演行、走位表"手里"列。表演翻译那一行只用来对照意图，它的措辞归 film-director。
- **怎么查**：每个表演拍子能不能回答"他在对她做什么"（试探、安抚、回避、逼问、打趣、安排）？关键情绪拍在第几镜、什么景别、几秒，前后有没有给它发生的时间？
- **失败信号**：表演行是状态描述（"他很紧张"）而没有冲着对方的行动；关键反应放在全景或越肩里；表演和走位脱节（站着不动地"激动"）；人物每镜从零起调。
- **哪一步可审**：分镜卡。**判定**：设计可审，表演质量看成片。
- **严重度**：关键拍子不可见、写成结果，重要。
- **依据**：Weston 区分"给结果"和"给可演的选择"；Mamet；Sundance 剪辑顾问 Gonçalves 提醒保险镜头会挤掉表演。

## 镜头语言关

### 每镜有当下的理由

- **怎样算好**：每镜答得出"观众此刻需要看到什么"；切点的动机埋在上一镜（视线、出画、声音、没解开的问题）；删掉故事也不缺的镜标成冗余；每组覆盖写明它在剪辑里的用途、服务哪一拍。
- **读哪里**：镜头纵览、各镜 C 层主要事件、覆盖逻辑。
- **怎么查**：逐镜问 Mackendrick 的问题"此刻需要看见什么"；对每个切点问"上一镜里是什么让观众想看下一镜"；对每组覆盖问 Sundance 的问题"这组覆盖是为了什么"。
- **失败信号**：建立—过肩—近景—反应—插入的模板场场一样；因为"有对话"而切，不因为信息变了而切；同一信息给两遍。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：覆盖模板代替视点重要；个别冗余镜提示。
- **依据**：Mackendrick《On Film-making》；Hitchcock 1967 年访谈（景别的变化要服务戏剧）；Sundance Directors Lab。

### 摄影机行为有规则

- **怎样算好**：本场有一条摄影机的常态规则和破规条件，并挂在人物状态上；每个运动写清谁或什么驱动它、相对人物是跟、领还是并行、终点构图揭示什么；静止也要有理由（按本剧的默认值换算：本剧默认手持时，固定反而要写为什么静）；推近的动机是人物内部的变化，不是"有情绪"；为方便而动的标出来。
- **读哪里**：机位表、各镜 C 层运镜、手法分布、卡头剪辑与透镜。
- **怎么查**：能不能用一句话说出本场摄影机的规则（"他掌控局面时锁定，失控时手持"）？逐个运动问驱动和终点；推近的那一刻，人物内部发生了什么？
- **失败信号**：运动只有执行描述没有驱动；对一张不变的脸缓推；每镜一种运动，没有逻辑；静止只是因为没想。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：没有动机的运动重要；规则没写出来但运动都合理，提示。
- **依据**：Fincher–Messerschmidt《杀手》；Żal《利益区域》；《心灵猎人》几乎不用手持与斯坦尼康；《1917》跟、领、并行三种关系；Hitchcock 1967（运动让观众跟着人物而注意不到摄影机）；film-director `director-lenses.md` 的误用信号。

### 变化有走向、峰值有落点

- **怎样算好**：景别、机距与焦距感、光、运动、动作幅度在 clip 内和跨 clip 有方向，不随机起伏；最极端的景别、唯一的运动、最大的明暗变化落在峰值拍；变化少而准，每次能指回一个剧情节拍或视点切换；跨集有可核对的递进计划。
- **读哪里**：各镜变化行、E 层峰值镜、场次纵览。
- **怎么查**：把景别序列写成一行（全 → 中 → 近 → 特 …），看它是一条曲线还是锯齿；对照峰值镜，看最紧的景别和首要的运动是不是给了它；每次变化问"是哪一拍要的"。
- **失败信号**：景别跳来跳去没有方向；峰值镜不是全条最可见的一镜；变化平均撒在每一镜；全条平（成片会被说"画面始终没有变化"）。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：峰值落空、变化没有方向、全条平，重要。
- **依据**：Lumet《十二怒汉》逐步换长焦、降机位，最后一镜换广角让观众透气；Block 的对比与亲和、故事强度与视觉强度曲线；Storaro《同流者》、Fincher《杀手》让画面随故事推进变化。

### 设计感镜头与破例登记

- **怎样算好**：设计感强的镜头（复杂运动、特殊角度、强风格光、长镜头、画外整句镜）数量少，只落在关键转折上；每个破惯例的镜头写明破了哪条、为什么；本剧规则的例外进登记，没登记的按违规。
- **读哪里**：手法分布、执行卡偏好冲突、E 层风险登记。
- **怎么查**：数设计感镜头有几个、落在哪几拍；逐个问理由。
- **失败信号**：设计感镜头平均撒在每条；破例没有登记；为了炫技牺牲表演或可读性。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：没登记的破例重要（违反硬规则则致命）；设计感过多提示或重要。
- **依据**：Lumet（被观众看穿的风格是坏风格）；Bordwell 的"有节制的炫技"；Jenkins 把强装置放在安静处；Lucy Forbes 偏好简洁；Mercado 专讲"何时打破规则"。

### 空间可读

- **怎样算好**：第一次切碎之前，观众知道谁在哪；越轴写明方法（镜内越过、中性镜、走位重画轴线）；三人以上定义主轴或分组；动作段能复原地理；相邻镜头之间的空间关系推得出来；机位轴不无故换。
- **读哪里**：空间锚点、机位表、核对、走位表。
- **怎么查**：只凭冷读能不能画出一张简图（谁在哪、门在哪、光从哪来）？数机位轴换了几次，每次为什么？每次换边有没有交代？
- **失败信号**：一开场就是近景、空间没建立；机位轴频繁换、景别跳来跳去，镜头语言不连贯；三人戏没有主轴；关键动作的地理不清。
- **哪一步可审**：方案、分镜卡。**判定**：设计可审，可读性看成片。
- **严重度**：观众失去方位、关键动作地理不清，重要。
- **依据**：Mackendrick 的"心理地理"；Fincher《杀手》的银幕方向规则；Arijon 三角形机位；《权力的游戏》"私生子之战"的技术预演。左右换算、方位一致归 film-director 机位设计核对，这里只判观众读不读得懂。

## 光与质感关

### 光有来源也有含义

- **怎样算好**：每处光都有画内或画外的叙事来源并写方向；同场正反打的主光方向相对空间不变；光比等级与故事调子对应；写明本场的光让观众看见什么、看不见什么；光的变化挂在具体节拍上；"危险就打暗"一类俗套被重新想过。
- **读哪里**：各镜光源行、贯穿要求的画面基调、变化行的光一维。
- **怎么查**：每个光源能不能在画面或空间里指出来？正反打的主光方向一致吗？光在哪一拍变、为什么？
- **失败信号**：光源一行只写"柔和暖光"没有方向；没有来源的顶光、缝隙光；光全程不变也没说为什么；光的含义靠俗套。
- **哪一步可审**：分镜卡（方案这一步只看卡头有没有光的思路）。**判定**：设计可审，质感看成片。
- **严重度**：光没有来源、正反打光向矛盾，重要；俗套提示。
- **依据**：Bradford Young、Lubezki、Żal（《利益区域》不加电影灯）；Gordon Willis、Storaro；Hitchcock 1967（光要有可信的来源）。

### 质感与参照统一

- **怎样算好**：有全剧统一的观感（色板、反差、柔度、饱和度），按场只做少量偏移，逐镜描述不越界；参照具体到片名、段落、借用的维度和不照搬的部分；"电影感""高级感"一类空词被追问理由。
- **读哪里**：贯穿要求、画面基调、图像简报。
- **怎么查**：本条的观感和全剧一致吗？参照是"像某部片"，还是"借某部片的哪一个维度"？
- **失败信号**：每条各写一种调子；空词；参照只给片名。
- **哪一步可审**：分镜卡。**判定**：设计可审，观感看试生成。
- **严重度**：提示，影响连续性时重要。
- **依据**：全剧一条显示 LUT（Deakins、Young）；《利益区域》拒绝会"强加观感"的镜头；Jenkins 与 Laxton 按场收窄参考；《曼克》回避戏仿。

### 参考资产计划服务设计

- **怎样算好**：每张资产对应一个镜头需求，决策载体指向它；场景图视角覆盖机位表的主要机位；图像简报把形容词翻成可比较的选择；绑定与上传顺序支持本条的视点与空间；首批生成当测试与样片对待，观感过关再批量。
- **读哪里**：资产清单、图像简报、场景图视角、决策载体。
- **怎么查**：每张图服务哪几镜？机位表里的主要机位有没有图覆盖？（本剧规则不许要求补图时，按规则改机位，不建议补图。）
- **失败信号**：资产和镜头需求对不上；一张场景图只服务一个反向镜；简报只有形容词。
- **哪一步可审**：分镜卡。**判定**：方案可审，观感看试生成。
- **严重度**：重要或提示。
- **依据**：《曼克》《切尔诺贝利》开拍前的测试；Netflix 开拍前的框线与样片流程；lookbook 按场收窄。

## 剪辑关

### 切点与节奏可读

- **怎样算好**：遮住台词，只看镜头和走位，能复述这一拍发生了什么；切点按情绪、故事、节奏、视线、画面平面、三维空间的顺序取舍，牺牲连续性要事先声明；镜长随强度变化，而不是一律的短；反应镜和所见镜的并置让观众得出预期的结论；很短的镜头主体单一、一眼看得清。
- **读哪里**：镜头纵览（时间、台词、无台词秒）、各镜主要事件、E 层反应镜清单。
- **怎么查**：用 `cold_read.py --mask-dialogue` 做静音测试；把镜长写成一行看它跟不跟强度走；逐个并置问"A 接 B，观众会得出什么结论"——是方案想要的吗？
- **失败信号**：静音测试讲不清；镜长均匀；无台词段没有功能；并置引出错误的结论；关键信息放在一两秒的镜头里还有好几个主体。
- **哪一步可审**：方案、分镜卡。**判定**：部分可审，实际节奏和视线看成片。
- **严重度**：并置导致错误结论致命；节奏平均、静音测试讲不清，重要。
- **依据**：Murch 的六条（情绪约占一半权重，空间最低）；Mackendrick（切点动机埋在上一镜）；Hitchcock 1967（短镜头要一眼可读）；Kuleshov 效应的实证有争议，所以按"观众会得出什么"审，不默认"接上就有意义"；NYU 第一学期的无对白默片练习。

### 跨 clip 接续

- **怎样算好**：本条末态就是下一条的起点（位置、朝向、持物、情绪）；clip 之间那一刀像剪辑一样有动机（动作、视线、声音），省略的时间写明；情绪和视点接力推进，不每条重新起调。
- **读哪里**：clip 起始与结束状态、复核、场次纵览、执行卡衔接行；上一条的结束状态。
- **怎么查**：上一条结束和本条开始之间那一刀的动机是什么？本条第一镜的情绪是不是从上一条末态起？
- **失败信号**：每条从零起调；省略没交代；视点在 clip 边界无理由换人；第一镜把上一条最后一拍再演一遍。
- **哪一步可审**：方案、分镜卡。**判定**：设计可审，接缝看成片。
- **严重度**：重要。
- **依据**：Lumet 跳拍时按情绪层级标注；本剧的情绪承接规则（若有）。

## 可行性关

### 精度与载体匹配风险

- **怎样算好**：设计精度集中在高依赖镜头（复杂走位、长纵深、动作、精确构图），这些镜头交给关键帧、白模或动作参考，而不是全靠文字；简单对话不被锁死到逐帧；高风险形式附风险清单与退路。
- **读哪里**：决策载体、E 层风险登记。
- **怎么查**：哪几镜是高依赖的？它们用的什么载体？有没有退路？
- **失败信号**：文字驱动的长纵深走位没登记；简单对话写成逐帧锁死；高风险段没有退路。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：重要或提示。
- **依据**：《1917》《银翼杀手 2049》的预视化只画高依赖段；剧集导演 Peter Hoar 给亲密戏画板、简单对话不规划；《混沌少年时》为大胆的收尾准备备选。

### 约束内做得完

- **怎样算好**：镜数、镜长、台词窗口和 clip 总长自洽；标出必需镜（只能保三镜时保哪三镜）；台词少而镜头多、或重要拍子分到的镜头反而少时要说出来；约束指生产格式（单条时长、单镜最短秒数、生成载体的能力），不指成本。
- **读哪里**：镜头纵览、时长、执行卡。
- **怎么查**：如果只能保三镜，方案自己知道保哪三镜吗？重要拍子分到的时间够不够？
- **失败信号**：关键拍 1 秒、次要过渡 4 秒；必需镜没标。
- **哪一步可审**：方案、分镜卡。**判定**：方案可审。
- **严重度**：提示，关键拍时间不够时重要。
- **依据**：《绝命毒师》第一副导演围绕每一镜最重要的东西排期。

## 裁决

标准之间、流派之间会打架。下面八条是从业者的调和办法，审阅时照用：

1. **按功能判，不按流派判。** 同一次强调可以靠调度，也可以靠剪切完成（Bordwell 把风格看成解决制作难题的方案）。审的是写没写清、成不成立，不是选了哪一派。
2. **镜头层不加修饰，系统层有表达。** 单镜描述要具体、不带评论性形容词（Mamet）；表达性放在跨镜头的递进计划里（Lumet、Block）。
3. **规则是默认值，例外必须写理由。** Mackendrick 不用"错误"这个词，只谈选择。写了理由的破例按选择评价，没写理由的按错误。
4. **冲突时按 Murch 的顺序取舍，并事先声明。** 情绪 > 故事 > 节奏 > 视线 > 画面平面 > 三维空间，从最低一项开始牺牲。AI 逐镜生成时，不事先声明"刻意不连续"，就分不清是设计还是生成出错。
5. **覆盖是保险，不是视点的替代。** 多拍一组镜头不能代替决定"这一刻跟谁"。
6. **每一拍声明观众被告知还是被扣留。** 告知与扣留都对，没想过才错。
7. **炫技跟着故事强度走。** 强装置只给关键转折。
8. **精度跟着风险走。** 高依赖镜头画细，简单对话留余地。

## 被关掉的手段

本剧规则常常关掉一部分经典手段。审阅档案里列着关掉了哪些、还剩哪些替代手段。审法：

1. 找出方案的递进和峰值靠什么完成；
2. 如果靠的正是被关掉的手段，按违反本剧规则处理；
3. 如果什么都没靠（递进和峰值落空），按"变化有走向、峰值有落点"判重要；
4. 意见里的方向只从替代手段里给。

例：本剧规定拍人一律平视，机位高度就不能编码权力；压迫的递进只能改由机距与焦距感、景别收紧、前景遮挡、光比与背景亮度来做。

## 与 film-director 的分工

| 事项 | film-director 脚本查 | 这里判 |
|---|---|---|
| 变化轨 | 镜长对比、两个维度各变一次、峰值不落在全景或越肩 | 变化的方向是否服务故事，峰值是否真是最重要的一拍 |
| 机位设计 | 有没有空间锚点、机位表、核对；写了方位时画左画右换算对不对 | 空间是否被设计成观众读得懂；机位是否为走位而设 |
| 无台词段 | 最长连续无台词过没过线 | 每段静默有没有功能、放在哪一拍 |
| 表演翻译 | 三段写没写、A 层词有没有进 C 层 | 表演拍子是不是冲着对方的行动、关键拍是否可见 |
| 台词 | 一句跨没跨镜、画外句的条件 | 这句话该落在谁的脸上（视点），反应放在哪 |
| 执行卡 | 25 行填没填、引的小节在不在 | 填的内容是否真成立 |

脚本已经报过的，这里不重报；脚本通过了，不等于设计成立。

## 失败信号速查

冷读时一眼能看出的毛病，对应到维度：

| 信号 | 维度 |
|---|---|
| 拍成"人在说话的照片"，台词在讲故事 | 调度先于机位；切点与节奏可读 |
| 跟着演员走，没决定这个镜头到底是什么 | 每镜有当下的理由 |
| 切点没有预埋动机 | 每镜有当下的理由 |
| 运动和风格喧宾夺主 | 设计感镜头与破例登记 |
| 用覆盖代替决定 | 视点与信息差；每镜有当下的理由 |
| 镜长一律短、特写用滥 | 变化有走向、峰值有落点；切点与节奏可读 |
| 表演写成情绪结果 | 表演写成可演的动作 |
| 没有递进，强度平均 | 变化有走向、峰值有落点 |
| 观众失去方位，机位轴频繁换 | 空间可读 |
| 悬念用错或不释放 | 视点与信息差 |
| 光没有来源，气氛靠俗套 | 光有来源也有含义 |
| 短镜头看不清、一镜好几件事 | 切点与节奏可读；约束内做得完 |
| 描述含糊、元素多余 | 每镜有当下的理由 |
| 基调和语法打架：意图写的是一种调子，调度与镜头用的却是另一种类型的语法 | 意图可追溯；视点与信息差 |
| 要观众看清的东西只在背景一小块 | 每镜有当下的理由（景别跟重要性走） |
| 亲密或对话戏用全身侧面站位 | 调度先于机位；每镜有当下的理由 |
| 先上镜头技术、后补戏剧结构 | 意图可追溯 |
